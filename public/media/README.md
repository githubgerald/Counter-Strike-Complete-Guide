# Movement clips

Put licensed or self-recorded demonstrations in this folder. Set the matching section's `media.src` in `content/guide.json` to `/media/filename.webm`, `/media/filename.mp4`, `/media/filename.gif` or `/media/filename.webp`.

Use current-build, uncut demonstrations with the route start, input overlay and landing visible. Keep source attribution in the section caption or research notes and check permission before redistributing somebody else's clip.

The guide includes an editable media placement for every section. No example clips are included in the project by default; an empty placement is only a place to add a demonstration, not evidence that the route has been reproduced.
